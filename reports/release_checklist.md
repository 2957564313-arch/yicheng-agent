## 发布阻断项

以下任一项未满足，不得宣称正式完成：

- 自动化测试或 60 例评估失败；
- 三个 Demo 中任意一个失败；
- 正式部署 URL 无法访问；
- 真实接口启用但没有失败降级；
- 仓库中出现真实 API 密钥。
