## 发布阻断项

以下任一项未满足，不得宣称正式完成：

- 自动化测试或 70 例评估失败；
- 三个 Demo 中任意一个失败；
- 正式部署 URL 无法访问；
- 真实接口启用但没有失败降级；
- 仓库中出现真实 API 密钥。

> 说明：Vercel 公网测试版的数据目录为临时存储。浏览器端快照可保障单台
> 设备上的课表、记忆和提醒设置体验，但跨设备长期保存仍是正式运营前的
> 发布阻断项。
