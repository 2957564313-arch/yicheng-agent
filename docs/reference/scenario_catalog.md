# 场景目录

当前离线验收包含 112 个用例，以下是面向使用者的主要场景分组。

## 单日时空规划

1. 在指定时间窗内组合学习、取快递、就餐、洗澡和运动。
2. 识别“上午、下午、晚上”等时段以及“晚上 7 点前”这类 24 小时制截止时间。
3. 处理固定会议、课程、就诊与其他可移动任务的先后依赖。
4. 根据校内地点、通勤时间、营业时间和天气约束生成可执行安排。
5. 没有直达路线时，用多段校内缓存路线保守估算并明确提示低置信度。

## 高频学习与生活任务

1. 复习、作业、课程项目、实验室协作和报告整理。
2. 早餐、午餐、购物、洗衣、休息和宿舍生活。
3. 会议、社团活动、行政事务、电话沟通和个人提醒。
4. 为每个任务单独识别地点、时长、时段和截止时间，避免相邻语句串扰。

## 计划变化与长期安排

1. 任务延长、迟到或新增事件后的局部顺延与计划差异。
2. 降雨等外部变化触发室外任务调整和全计划重算。
3. 周目标拆分、阶段依赖、重复次数、个人课表和空闲容量分配。

## 降级与澄清

1. 在线模型、实时路线或天气不可用时，保留规则解析和静态数据兜底。
2. 关键信息不足时先提出澄清问题，不虚构时长、地点或截止时间。
3. 计划不可行时保留全部用户任务，并给出缺口和可恢复建议。
